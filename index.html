ShokaCraft（ショカクラフト）は、日本語の小説のためのデスクトップエディタです。ルビも縦書きも投稿サイトの文字数もそのまま扱え、伏線や引きの設計、設定資料、バージョン保存までを一つの画面にまとめました。

できること

いちばん大事なのは、原稿を失わないこと。そのうえで、日本語の小説に要るものを揃えました。

原稿を失わない

自動保存と、保存に失敗した時の退避。原稿ごとに世代を残し、いつでも「この時点に戻す」ことができます。

ルビ・傍点・縦書き

｜漢字《かんじ》 や傍点を、書きながらその場で表示。縦書きのプレビューで仕上がりを確かめられます。

投稿サイトの文字数

なろう・カクヨムと同じ数え方の文字数と原稿用紙換算。各サイトの記法に合わせて書き出せます。

設定Wiki

登場人物や世界観を Markdown で。本文に出てきた設定は、書いている横にカードで並びます。

糸の設計

引き・焦らし・売り、そして伏線。本文に小さな印を置くだけで、物語の緊張の流れと未回収の伏線が見えます。

バージョン保存

「バージョンを保存」と「履歴を見る」だけで Git を使えます。GitHub へのバックアップと、複数の端末での執筆にも。

ダウンロード

最新版 0.1.0。お使いの OS のものを選んでください。

配布物は準備中です。公開したら、ここからダウンロードできるようになります。

macOS Apple シリコン・Intel

ShokaCraft-macos.dmg ディスクイメージ

開いたら、ShokaCraft をアプリケーションフォルダへドラッグします。

「開発元を確認できないため開けません」と出たら

プレビュー版は Apple の公証を受けていません。Finder でアプリを右クリック →「開く」を選ぶと、次からは普通に開けます（システム設定 → プライバシーとセキュリティ の「このまま開く」でも同じです）。

Windows 10・11（64 ビット）

ShokaCraft-windows-setup.exe インストーラー ShokaCraft-windows.msi MSI（管理者向け）

ふつうは上のインストーラーを使ってください。

「Windows によって PC が保護されました」と出たら

プレビュー版には署名がありません。「詳細情報」→「実行」で進めます。

Linux x86_64

ShokaCraft-linux.AppImage どのディストリビューションでも ShokaCraft-linux.deb Ubuntu・Debian
使い方

AppImage は chmod +x ShokaCraft-linux.AppImage で実行できるようにしてから開きます。deb は sudo apt install ./ShokaCraft-linux.deb。日本語入力には fcitx5 か IBus（Mozc など）をお使いください。

過去の版と変更点は リリースの一覧 にあります。

利用について

ShokaCraft はオープンソースではありません。配布しているのはアプリだけで、ソースコードは公開していません。アプリの再配布・改変・リバースエンジニアリングはご遠慮ください。

プレビュー版は、原稿を失わないことを最優先に作っていますが、動作の確認が済んでいない機能があります。大切な原稿は、バージョン保存や別の場所へのバックアップと併せてお使いください。
