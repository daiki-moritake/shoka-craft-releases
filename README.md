# ShokaCraft（ショカクラフト）

日本語の小説を書くためのデスクトップエディタです。macOS・Windows・Linux で動きます。

**配布ページ: https://daiki-moritake.github.io/shoka-craft-releases/**

ダウンロードは配布ページか、このリポジトリの [Releases](https://github.com/daiki-moritake/shoka-craft-releases/releases) から。

## このリポジトリについて

このリポジトリは配布のためだけのもので、アプリ（配布物）と配布ページだけを置いています。
**ShokaCraft はオープンソースではありません。** ソースコードは公開していません。
アプリの再配布・改変・リバースエンジニアリングはご遠慮ください。
